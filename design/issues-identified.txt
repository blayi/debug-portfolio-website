Approach

I corrected the shared HTML structure first, then completed each page’s missing content. I added accessible labels, alternative text, form validation, and semantic elements. After completing the HTML, I created a consistent olive design, styled the navigation, table, form, and projects, and added responsive layouts. Finally, I tested every link and form control and validated all HTML and CSS using the W3C validators.
